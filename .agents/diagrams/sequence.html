Insurer · Sequence: полный процесс

Одна страница, семь этапов. Основной сценарий идёт сверху вниз; Activity работает параллельно. id — заявка CLM-1001, T — UUID запуска.

1. Запуск и инструкции2. Создание LangChain-агента3. Цикл инструментов4. Запись решения5. Проверка и симуляция выплаты6. Завершение и действия пользователя7. Activity и SSE

1. Запуск и инструкции

Run → backend POST /run → сервис агента POST /runs → backend POST /start → GET /api/instructions. Ответ 202 подтверждает приём запуска. Полученные instructions и policy_wording код агента объединяет в systemPrompt.

Открыть этап отдельно ↗

2. Создание LangChain-агента

instructions + policy_wording → systemPrompt → createAgent → сообщение role: system для LLM. User-сообщение и схемы тулов передаются отдельно.

Открыть этап отдельно ↗

3. Цикл инструментов

get_claim показан как пример. Порядок дальнейших вызовов выбирает LLM.

Открыть этап отдельно ↗

4. Запись решения

record_decision → API → SQLite. Решение ещё не означает выплату.

Открыть этап отдельно ↗

5. Проверка и симуляция выплаты

До $1,000 включительно — pay_claim. Большая сумма требует sign-off обработчика.

Открыть этап отдельно ↗

6. Завершение и действия пользователя

Финальный ответ → /finish. Затем при необходимости отдельные sign-off и /pay.

Открыть этап отдельно ↗

7. Activity и SSE

Параллельный поток: история и новые события передаются интерфейсу по мере выполнения.

Открыть этап отдельно ↗
